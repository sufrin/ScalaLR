# Stage 1: First Language atop Bootstrap

The `stage1` module defines a generator that maps the bootstrap scalalr 
language (as defined in `stage1-notation.scalalr`) into the usual Scalalr 
components in Components.scala, Tables.scala, 
Scanner.scala, and Reduction.scala. 

These components
must be installed in an appropriate place in
the source tree of the module `scala1` before that module can be
compiled, packaged, and the packaged form made runnable.

The details are handled by the script:

    preparestage1

that uses the bootstrap scalalr code generator to generate the
next stage of scalalr from the scalalr notation description, and
sbt and scala-cli to deal with module compilation and 

    forgiving-stage1-notation.scalalr

The input language of this stage is more or less identical to that of
the current bootstrap code generator; and the code generated by them is
functionally indistinguishable.
